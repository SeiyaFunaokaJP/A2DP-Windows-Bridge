## 前提条件

- **Windows 10 (22H2) / 11** (x64 または ARM64)
- **BlueCaster 用の USB Bluetooth アダプター**: 別の USB ドングルを推奨。USB 接続の内蔵アダプターも使えますが、その間 Windows の Bluetooth は使えません（[手順 2](#winusb) 参照）

BlueCaster はアダプターへの WinUSB ドライバーの割り当てを自分で行います。[Zadig](https://zadig.akeo.ie/) はもう必要ありません（使うこともできます。[Zadig を使う場合](#zadig)を参照）。

## BlueCaster のインストール

[リリース](https://github.com/SeiyaFunaokaJP/BlueCaster/releases)ごとに、中身が同じ 2 つの形式があります。

- **インストーラー版**（`BlueCaster-<バージョン>-win64-setup.exe`、ARM64 では `-arm64-setup.exe`）：管理者権限なしで現在のユーザーにインストールします。スタートメニュー（**BlueCaster**）とアンインストーラーを追加し、Microsoft Edge WebView2 ランタイムがなければ一緒にインストールします（Windows 11 には標準で入っています）。更新はアプリの中から入れられます（**設定 > 更新 > 今すぐ更新**）
- **ポータブル版**（`BlueCaster-<バージョン>-win64-portable.zip`、ARM64 では `-arm64-portable.zip`）：任意の場所に展開して `bluecaster.exe` を実行します。3 つのプログラム（`bluecaster.exe`、`bluecaster-core.exe`、`bluecaster-driver.exe`）は同じフォルダーに置いたままにしてください。ポータブル版は更新を知らせるだけです。WebView2 ランタイムが入っている必要があります

どちらも設定・プロファイル・リンクキー・ファームウェアを `%APPDATA%\BlueCaster` に保存するため、相互に切り替えられます。アンインストールすると、**ユーザーデータを削除する** をオフにしない限りこのフォルダーも削除されます（サイレントでのアンインストールでは残ります）。 プログラムは `%LOCALAPPDATA%\BlueCaster\` に入り、ライセンス文は `licenses\` フォルダーに置かれます。

### v1 からの乗り換え {#from-v1}

v1 の上から v2 のインストーラーを実行してください。**インストール準備完了** のページに、先にアンインストールする以前のバージョン（v1、または 2.0.0 から 2.0.2-beta.5 まで）が示されます。v1 が動いていれば終了を促し、v1 をアンインストールしてから、設定フォルダーはそのまま残します。プロファイル、ヘッドホンとのペアリング、ファームウェアのファイルは引き継がれ、ヘッドホンのペアリングし直しは要りません。（Zadig で）WinUSB を入れてあるアダプターはそのまま使えます。**Windows 起動時に開始** がオンだった場合は、v2 が起動するように変わります。

v2 は初回起動時に、v1 の設定を `%APPDATA%\BlueCaster\backup\v1\` にコピーしてから読み込みます。

### 2.0.x（A2DP Windows Bridge）からの乗り換え {#from-2x}

BlueCaster 3.0.0 は A2DP Windows Bridge の新しい名前です。インストールされている 2.0.x の上から 3.0.0 のインストーラーを実行してください。セットアップが古いバージョンを自動でアンインストールし、設定はそのまま残ります。スタートメニューの項目と **Windows 起動時に開始** の項目は「BlueCaster」に変わります。

3.0.0 は初回起動時に、フォルダー `%APPDATA%\A2DPWB` を `%APPDATA%\BlueCaster` に名前変更し、中のファイルをサブフォルダーに整理します（[設定とファイル](architecture#settings-and-files)）。`backup\v2\` に 2.0.x の設定とペアリングのコピーがあるので、2.0.2 をインストールし直すときは、それらのファイルを `%APPDATA%\A2DPWB` にコピーして戻してください。

ヘッドホンには、ペアリングし直すまで古い Bluetooth 名「A2DPWB」が表示され続けることがあります。

## 手順 1: 初回セットアップ {#first-run}

USB Bluetooth アダプターを挿して BlueCaster を起動します。オーディオデバイスがまだないとき、または WinUSB のアダプターがないときは、**セットアップウィザード** が開きます。手順は 4 つです。

1. **アダプタを選ぶ**: 見つかった USB Bluetooth アダプターの一覧です。見当たらなければ、アダプターを挿してから **再検出** を押します。BlueCaster が使えるかどうかを、緑の **対応**、オレンジの **実験的**、赤の **非対応** で示します。非対応のものは一覧に出ますが、選べません
2. **ドライバとファームウェア**: 行う内容が一覧で示され、**このアダプタを準備** でそれを実行します。アダプターのドライバーを WinUSB に置き換え（Windows が管理者の許可を求めます。[手順 2](#winusb)を参照）、アダプターに必要な Realtek のファームウェアのファイルをダウンロードします（[ファームウェア](#firmware)を参照）。BlueCaster がダウンロードできないファームウェアは、手動でファームウェアフォルダーに置きます
3. **オーディオ機器を探す**: 検索は自動で始まります。オーディオ機器をペアリングモードにして、その横の **接続** を押します（アドレスを入力して **使う** でも可）。BlueCaster が機器を最良のコーデック（自動）で保存して接続します。機器は **ペアリング済みの機器** の下に状態を示す点つきで表示され、検索は止まります。**デバイスを追加** を押すとその機器を切断して検索を再開するので、別の機器を追加できます。切断した機器は保存されたままで、間違えた機器はそこで削除できます。Windows がこのアダプターで機器をペアリングしていたときは、**Windows のペアリングを取り込む** が表示されます（[手順 3](#headphones)を参照）。VB-Cable が入っていれば新しい機器はそれをキャプチャします。なければこの手順で必要な理由を **VB-Cableをダウンロード** とともに示し、後で BlueCaster が初めて VB-Cable を見つけたときに、System Loopback の機器をそれに切り替えます。機器のコーデックはあとで **コーデック** 画面で変えられます
4. **全般設定**: テーマ、**起動**、**通知**、更新の確認。設定と同じ項目で、すぐ保存されます。初めてのセットアップでは **Windows 起動時に開始** と **トレイに入れた状態で起動** をオンにします

**あとで設定する** で残りを飛ばせます。**設定 > セットアップを実行** でもう一度開けます。

## 手順 2: アダプターに WinUSB を割り当てる {#winusb}

BlueCaster は、Windows に標準で入っている汎用 USB ドライバー WinUSB を通して USB Bluetooth アダプターと直接通信します。**専用のアダプター**をおすすめします。内蔵 Bluetooth は通常の Windows Bluetooth として引き続き使用できます。

1. **アダプタ** 画面を開きます（セットアップの **ドライバとファームウェア** では、**このアダプタを準備** で手順 2〜4 を行います）
2. アダプターの **ドライバ** が **元のドライバ**（または **ドライバなし**）になっています。Windows やメーカーが入れたドライバで、これを WinUSB に置き換えます。**WinUSB ドライバに置き換える** を押します
3. 確認の内容を読んで続けると、Windows が管理者の許可（UAC）を求めます
4. ドライバが **WinUSB ドライバ** になります

アダプターが使用中で Windows がすぐに WinUSB を読み込めなかったときは、BlueCaster がその旨を表示し、ドライバの行に **差し直すか Windows を再起動** と出ます。アダプターを抜いて差し直してください。内蔵アダプターの場合は Windows を再起動します。それまでは接続しようとすると、ログに `failed to initialize WinUSB (error 50)` が出て失敗します。

{: .warning }
WinUSB を割り当てている間、Windows の Bluetooth からそのアダプターは見えなくなり、そのアダプターで Windows にペアリングしたデバイスはドライバーを戻すまで使えません。通常の周辺機器（キーボード、マウス等）には内蔵 Bluetooth を使用してください。USB 接続の内蔵アダプター（多くのノート PC の Realtek 製など）を BlueCaster に使うこともできますが、ドライバーを戻すまで **PC で Windows の Bluetooth がまったく使えなくなります**（Bluetooth 設定、マウス、キーボード、ほかのオーディオ機器）。

同じ画面の **元のドライバに戻す** で、アダプターを Windows に戻せます。Windows がドライバー（通常は Windows の Bluetooth ドライバー）を選び直し、Windows の Bluetooth でそのアダプターを使えるようになります。WinUSB を割り当て直すまで、BlueCaster はそのアダプターで配信できません。Windows が動かす Bluetooth アダプターは一度に 1 つだけです。ほかのアダプターが使われているときは、戻したあとに BlueCaster がその旨を表示します。このアダプターを Windows で使えるのは、デバイス マネージャーでそちらを無効にし、このアダプターを挿し直してからです。BlueCaster でペアリングし直したヘッドホンはキーが新しくなっているため、Windows の古いペアリングでは接続できないことがあります。ダイアログには Windows でもペアリングしている機器の名前が出ます。接続できないものは Windows の設定で削除して、ペアリングし直してください。アンインストーラーも同じことができます。アンインストール ウィザードの 1 ページに **元の Bluetooth ドライバーに戻す**（BlueCaster が WinUSB を割り当てたアダプターがあるとき。管理者の許可を一度求めます）と **ユーザーデータを削除する**（`%APPDATA%\BlueCaster` の設定、コーデック、ペアリング、ファームウェアと、**対応しているコーデックのみ表示** などウィンドウが覚えている内容）があり、どちらも最初からオンです。更新のときと、サイレントでのアンインストール（`/S`）では WinUSB のまま残ります。

### Zadig を使う場合 {#zadig}

[Zadig](https://zadig.akeo.ie/) で入れた WinUSB ドライバーでも同じように動きます。

1. Zadig を開き、**Options > List All Devices** を選択
2. ドロップダウンから USB Bluetooth アダプターを選択
3. ターゲットドライバーとして **WinUSB** を選び、**Replace Driver** をクリック

### デバイス マネージャーで手動で行う {#device-manager}

BlueCaster の一覧にアダプターが出てこない、**アダプタ** 画面のボタンが失敗する、同じ種類のほかのアダプターと動きが違う、といった場合は、Windows のデバイス マネージャー（**スタート** を右クリック > **デバイス マネージャー**）で同じことを手動で行えます。どちらも管理者の権限が要ります。メニューの名前は Windows の版によって少し違うことがあります。

**WinUSB ドライバに置き換える**

1. アダプターを探します。通常は **Bluetooth** の下に製品名（例: 「TP-Link Bluetooth USB Adapter」）で出ています。ドライバーの起動に失敗しているときは黄色の印が付きます。**表示 > デバイス (接続別)** にすると、PC 内蔵の Bluetooth と見分けやすくなります（BlueCaster に使うのでなければ、内蔵のほうには触らないでください）
2. 右クリック > **ドライバーの更新** > **コンピューターを参照してドライバーを検索** > **コンピューター上の利用可能なドライバーの一覧から選択します**
3. デバイスの種類を聞かれたら **ユニバーサル シリアル バス デバイス** を選びます。**互換性のあるハードウェアを表示** のチェックを外し、製造元 **WinUsb デバイス**、モデル **WinUsb デバイス** を選んで **次へ** を押し、警告を確認します
4. アダプターは **ユニバーサル シリアル バス デバイス** の下に **WinUsb デバイス** として出ます。BlueCaster を起動し直す（または **アダプタ** 画面を開き直す）と、Zadig の場合と同じように使えます

**元のドライバーに戻す**

1. **ユニバーサル シリアル バス デバイス** の下のアダプター（**WinUsb デバイス**）を右クリック > **デバイスのアンインストール**。WinUSB ドライバーを Zadig で入れた場合は **このデバイスのドライバーを削除しようとしました** にもチェックを入れます（入れないと Windows がまた Zadig のドライバーを選びます）
2. アダプターを抜いて挿し直します（または **操作 > ハードウェア変更のスキャン**）。Windows が自分のドライバーを入れ、アダプターは **Bluetooth** の下に出ます
3. そこで黄色の印が付いた場合（ドライバーの起動に失敗。例: コード 31）は、メーカーのドライバーがそのアダプターで動いていません。右クリック > **ドライバーの更新** > **コンピューターを参照してドライバーを検索** > **コンピューター上の利用可能なドライバーの一覧から選択します** > **汎用 Bluetooth アダプター** を選ぶか、BlueCaster で使うなら上の手順で WinUSB を割り当て直してください

## 手順 3: ヘッドホンを探す {#headphones}

**デバイスを検索**（**オーディオデバイス** にあります）は、USB アダプターで近くのデバイスを 30 秒探し、応答した順に表示します。セットアップでは検索が自動で始まり、デバイスを接続する（**デバイスを追加** でそのデバイスを切断し、検索を再開します）、**検索を停止** を押す、セットアップを閉じるのいずれかまで続きます。先にヘッドホンをペアリングモードにしてください。BlueCaster で以前ペアリングしたデバイスには **ペアリング済み** と付きます。

検索で見つからないときは、**手動入力:** に Bluetooth アドレスを入れて **使う** を押します。入力・貼り付けたアドレスはその場で整形されます: `AA:BB:CC:DD:EE:FF`、`aa-bb-cc-dd-ee-ff`、`AABBCCDDEEFF`、`AA BB CC DD EE FF` はどれも `AA:BB:CC:DD:EE:FF` になります。

WinUSB を割り当てる前に Windows がこのアダプターでペアリングしたヘッドホンは、そのペアリングを引き継げます。**Windows のペアリングを取り込む**（**オーディオデバイス** とセットアップにあり、該当する機器があるときに表示されます）でペアリングを引き継ぐと、ペアリングモードにせずに接続できます。Windows が管理者の許可を求めます。

**Windows 設定から確認**（ヘッドホンを PC 内蔵の Bluetooth とペアリングしている場合）:
1. **設定 > Bluetooth とデバイス** を開く
2. オーディオデバイスをクリック
3. **プロパティ** をクリック
4. Bluetooth アドレスが表示される（形式: `AA:BB:CC:DD:EE:FF`）

**コマンドラインから確認**（先に BlueCaster を終了してください。トレイ > **終了**）:
```
bluecaster-core.exe --cli --scan
```

ヘッドホンは、コーデック（**コーデック** 画面）が **自動**、出力ソース（**オーディオデバイス** 画面）がシステムの音で始まります。初期設定のままで一番良い音になります。そのほかは[使い方](usage)をご覧ください。

## ファームウェア（Realtek アダプター） {#firmware}

Realtek ベースの USB Bluetooth アダプター（TP-Link UB500、RTL8761BU ドングル等）は動作に専用ファームウェアが必要です。CSR アダプターはファームウェア不要です。Intel、MediaTek MT79xx、Qualcomm、Broadcom のアダプター（試験的）は、それぞれのファームウェアファイルが必要な場合があります。[推奨アダプター](#adapters)を参照してください。

### アプリでの案内（ガイド付きダウンロード）

**アダプタ** 画面（とセットアップの **ドライバとファームウェア**）に、アダプターのファームウェアの状態が出ます: **ファームウェアOK**、**Realtek のファイルは不要**、または必要なファイル名付きの **ファームウェアが見つかりません**。**ダウンロードページを開く** ボタンでブラウザの [linux-firmware/rtl_bt](https://git.kernel.org/pub/scm/linux/kernel/git/firmware/linux-firmware.git/tree/rtl_bt) ページを開き、**ファームウェアフォルダを開く** で保存先フォルダーを開きます。必要な `.bin` ファイルをダウンロードしてフォルダーに配置します。

**Bluetooth チップ** の一覧にあるチップなら、**ファームウェアをダウンロード** で同じことができます。確認のあと、BlueCaster が linux-firmware (kernel.org) からファイルをダウンロードし、それぞれ SHA-256 を照合してファームウェアフォルダーに保存します。linux-firmware に config ファイルがないチップには空の `_config.bin` を置きます（チップは自身の設定を使います）。ファイルは BlueCaster に含まれておらず、ボタンを押したときにだけダウンロードされます。

BlueCaster はアダプターのチップセットを検出し、必要なファームウェアファイル名を表示します。

ファームウェアがなくても Realtek のアダプターは ROM のコードで開いて応答するため、一見正常に見えますが、接続やストリーミングに失敗します。BlueCaster はそのとき、ファームウェアが読み込まれていないと表示します。また、以前のセッションで書き込んだファームウェアはアダプターの電源が切れるまで残るため、ファイルを消しても PC を再起動するかアダプターを抜くまでは動き続けることがあります。

### Bluetooth チップの設定

**アダプタ** 画面の **Bluetooth チップ** の一覧で、アダプターに Realtek の初期化（ファームウェアの書き込み）を行うかどうかを決めます。

| 選択肢 | 意味 |
|:-------|:-----|
| **自動**（既定） | BlueCaster の起動ごとに、検出したアダプターから判定します。既知の Realtek アダプターならそのチップ、それ以外のアダプターなら Realtek の初期化を行いません |
| **Realtek 以外** | Realtek の初期化を行いません。Intel、Broadcom、CSR などのアダプターを自動で判別できない場合に選びます |
| **RTL8761BU**、**RTL8822CU** など | その Realtek チップとして扱います。自動で判別できない Realtek 系アダプター（独自の VID:PID を持つ OEM 製品）で必要です。状態欄に `.bin` ファイルがファームウェアフォルダーにあるかが表示されます |
| **Custom** | ファームウェアフォルダーの `custom_fw.bin` と `custom_config.bin` を使います |

Realtek 以外のアダプターに Realtek チップや Custom を選ばないでください。Realtek ファームウェアを書き込もうとするため、アダプターが起動しない場合があります。

### 手動ダウンロード

1. [linux-firmware/rtl_bt](https://git.kernel.org/pub/scm/linux/kernel/git/firmware/linux-firmware.git/tree/rtl_bt) からチップセット用のファームウェアと設定の `.bin` ファイルをダウンロード（例: `rtl8761bu_fw.bin` と `rtl8761bu_config.bin`）
2. BlueCaster のファームウェアフォルダー（`%APPDATA%\BlueCaster\firmware`。**ファームウェアフォルダを開く** でも開けます）に両ファイルを配置

{: .note }
これらのファームウェアファイルは linux-firmware プロジェクト経由で配布される Realtek 独自のバイナリです。本リポジトリには含まれていません。再配布条件については [WHENCE](https://git.kernel.org/pub/scm/linux/kernel/git/firmware/linux-firmware.git/tree/WHENCE) を参照してください。

## 推奨アダプター {#adapters}

BlueCaster で実際に使われたアダプターとヘッドホンは、コーデックや報告とあわせて [検証済みの機器](hardware)にあります。

| チップセット | 製品例 | 備考 |
|:-------------|:-------|:-----|
| Realtek | TP-Link UB500、RTL8761BU | ファームウェアのダウンロードが必要（上記参照）。最も検証済み |
| CSR | CSR8510 汎用ドングル | そのまま動作、ファームウェア不要 |
| Barrot | Bluetooth 5.4 / 6.0 ドングル（`33FA:0010`、`33FA:0012`） | ROM ファームウェアで動作、ファームウェア不要。ユーザー報告は今のところ 1 件 |
| Marvell | Microsoft Surface Pro / Surface Book 内蔵（88W8897） | *試験的。* ファームウェアファイルは不要: Bluetooth のファームウェアも Wi-Fi ドライバーが読み込むため、Wi-Fi はオンのままにしてください。実機では未テスト |

USB Bluetooth 5.0 以上のアダプターは、LDAC のような高ビットレートコーデックに最適です。

複数のアダプターに WinUSB を割り当てていると、BlueCaster は最初に見つけたものを使います。WinUSB は BlueCaster で使うアダプターだけにしてください。
